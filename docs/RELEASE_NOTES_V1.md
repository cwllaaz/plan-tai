## 2. 模块交付

| 模块 | 负责人 | 分支 | 交付 |

## 3. 交付物

```
dist/计划台-1.0.0-win64/
├─ jihuatai.exe              # 主程序
├─ flutter_windows.dll       # Flutter 运行库
├─ cnativeapi.dll            # sqlite3 原生资产
├─ dartjni.dll               # JNI 支持
├─ data/                     # Flutter 资源（icudtl.dat、flutter_assets）
├─ README.md
├─ 用户操作说明.md
├─ 数据库与备份说明.md
├─ 测试报告.md
└─ 已知问题.md
```

另提供 `dist/计划台-1.0.0-win64.zip`。

## 4. 数据位置

- 数据库：`%APPDATA%\计划台\data\app.db`（WAL）
- 备份：`%APPDATA%\计划台\data\backups\`
- 便携覆盖：`JIHUATAI_DATA_DIR`
- 演示模式：`JIHUATAI_DEMO=1`
