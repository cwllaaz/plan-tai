# 计划台 · 产品规格（V1.0）

> 状态：V1.0 基础架构已冻结，业务模块（日历 / 每日面板 / 本地数据）待并行开发。
> 本文是范围基线；技术细节见 [ARCHITECTURE](ARCHITECTURE.md)，数据规则见 [DATA_CONTRACT](DATA_CONTRACT.md)。

## 1. 一句话定位

**计划台是一张"项目的月历"**：把同时推进的多个长期项目、每个项目的跨天阶段、每天的若干任务，压缩到一张月历上；双击任何一天，就能在右侧把当天的事全部处理掉，不离开月历。

它不是待办清单（以清单为入口），不是甘特图（看依赖与工期），不是团队协作工具，也不是精确计时工具。

## 2. 要解决的三层问题

| 层次 | 痛点 | 计划台的回答 |
|---|---|---|
| 看得见（全局） | 项目多、跨度长，记不住"这周有哪几条线在跑" | 月历 + 跨天彩条 |
| 分得清（归口） | 任务混在一起，不知道属于哪个项目 | 项目色贯穿月历、抽屉、侧栏 |
| 做得掉（执行） | 待办清单看不到"今天该干什么" | 双击日期 → 右侧时间轴 + 完成率 |

核心创新是第 1、2 层的结合：**跨天阶段（PlanSpan）与单日任务（PlannerTask）在同一个格子里共存，但视觉上分明**。

## 3. 目标用户与场景

V1 面向单用户、本地优先的个人项目管理者（如同时推进 2–5 个长期项目的学生 / 独立开发者）。

- **周日晚上排下周**：切到周视图（V1.5）看跨天条落在哪几天，把任务拖进空档。
- **早上开工**：打开就是月历，今天格子里有 5 件事 → 双击今天 → 右侧时间轴 → 勾掉一件，完成率同步更新。
- **临时变更**：老师临时加会 → 双击周五 → 3 分钟内加一条任务 → 关闭抽屉，月历已更新。
- **月底复盘**：V1.5 的统计页看各项目投入；V1 先保证数据留痕。

## 4. V1 范围

### 4.1 做

1. **Windows 原生桌面应用**（Flutter AOT 编译为 exe），不是网页套壳。
2. **月历主页**：周一开头的 6 周网格；今天 / 选中日期样式；跨天阶段彩条（含跨月分段、车道分配）；单日任务条目；溢出计数；悬停完整信息。
3. **双击日期 → 右侧每日面板（420px）**：按时间排序的任务时间轴、无时间任务分组、完成勾选、任务增删改、重叠提示、当日备注与「当日重点」。
4. **项目**：名称、颜色（8 色板）、状态（进行中 / 暂停 / 归档）、排序。
5. **本地持久化**：SQLite，单机、离线、无账号。
6. **备份/恢复**：手动导出 JSON 备份并校验版本（V1 验收项）。
7. **演示数据模式**：未接入数据库时可运行、可截图、可并行开发 UI；界面必须明确标注。

### 4.2 不做（V1 明确排除）

- 周视图 / 日视图（V1.5；外壳已预留分段控件但禁用）。
- 统计页、时间记录、番茄钟。
- 云同步、账号、多人协作、评论、提醒推送。
- 深色主题（令牌已语义化，V1.5 只换色值）。
- Android / Web / Ubuntu 打包。
- 拖拽调整跨天阶段起止（V1.5 列为候选）。
- 甘特图、依赖关系、资源负载。

## 5. 关键流程（必须顺畅的一条路）

```
打开软件 → 月历
  → 单击某天（选中高亮，不改布局）
  → 双击该天空白（右侧面板展开，月历收窄不重排）
  → 面板内：勾选完成 / 改时间 / 加任务 / 写当日备注
  → 关闭面板（Esc 或点关闭）→ 月历对应格子即时刷新
```

这条路径上任何一次页面跳转都是设计失败。**"不离开月历就能管完一天"是硬指标。**

## 6. 验收标准

### 6.1 基础架构（本阶段，已完成）

- `flutter analyze` 零问题；`flutter test` 全绿（当前 60 个用例）。
- `flutter build windows --release` 产出可启动 exe，窗口标题、最小尺寸、居中生効。
- 公共模型、仓储接口、主题、模块接口冻结并提交。
- 内存仓储可独立驱动 UI，不需要数据库。
- 三个并行工作区与分支就绪。

### 6.2 V1 产品验收

1. 双击日期到面板可交互 ≤ 200ms（本地数据，无网络等待）。
2. 1366×768、125% 缩放下 7 列不横向滚动，格内文字不重叠、不裁切。
3. 单日 12 条任务时，格子显示 3 条 + `+9 项`，布局不破。
4. 一条跨 11 天的阶段在月历上正确切成 3 段（含跨月），每段首尾圆角与延续指示正确。
5. 关闭软件、重启 Windows、再打开，数据与昨天一致。
6. 备份文件可在全新安装的机器上恢复出同样的月历。
