## 1. 设计原则

1. **克制**：1px 边框分隔，阴影只用于浮层；无涟漪、无渐变、无大面积色块。
2. **低饱和**：项目色只用于识别，不做装饰；正文以墨色层级表达主次。
3. **日历优先**：任何交互都不离开月历；面板是"侧边抽屉"而不是新页面。
4. **信息密度可读**：格子内最多 2 条跨天条 + 3 条任务，超出必须折叠为 `+N`。
5. **明确反馈**：不可用功能显示"即将 / 后续版本"并给出 tooltip，不伪装成功。

## 3. 间距 / 圆角 / 尺寸

- 间距：`2 / 4 / 8 / 12 / 16 / 20 / 24 / 32`（全部 4 的倍数）。
- 圆角：控件 `6`，卡片 `8`，面板 `10`，胶囊 `999`。
- 侧栏宽 `224`（折叠版 `56`，V1 不做折叠交互）。
- 顶栏高 `56`；品牌区与顶栏同高。
- 右侧抽屉 `420`（允许 360–480，V1 固定 420）；与月历用 1px 边框分隔。
- 月历格子最小高 `96`，内边距 `6`。
- 窗口最小 `1100×700`，默认 `1440×900`，居中。
- 阴影：卡片 `0 1px 2px rgba(16,24,40,.06)`；浮层 `0 12px 32px -8px rgba(16,24,40,.16)`。

## 4. 字体与字号

- 字体：`Microsoft YaHei UI` → `Microsoft YaHei` → `PingFang SC` → `Noto Sans SC` → `Segoe UI`。
  V1 不打包字体（离线、体积、许可考虑），V1.5 再评估。
- 字号层级：`11` 辅助 / `12` 次要 / `13` 正文紧凑 / `14` 正文 / `16` 卡片标题 /
  `20` 面板标题 / `24` 日期大标。行高 1.45（大标 1.2–1.3）。
- 数字（日期、时间、计数）启用 `FontFeature.tabularFigures()`，避免抖动。
- 字重：标题 `w600`，强调 `w500`，正文 `w400`。不使用 `w700` 以上。

## 5. 月历格子信息预算

在 1366×768、125% 缩放下，格子约 96×100 逻辑像素，必须分层：

```
┌─────────────────────────┐
│ 16      ●●●  +2          │  行 0：日期数字 + 项目色点（≤3）+ 溢出提示
│ ▬▬▬▬▬▬▬▬▬▬▬▬              │  行 1-2：跨天条车道（≤2，超出 "+N 条安排"）
│ ○ 09:00 相机调试          │  行 3-5：任务条目（≤3，超出 "+N 项"）
└─────────────────────────┘
```

- 日期数字 24×24 圆形：今天 = accent 实底白字；选中 = 白底 + accent 描边；
  非本月 = `textDisabled`。
- 选中格：`accentSoft` 55% 底 + 左侧 2px accent 竖线（替代整圈描边，避免与网格线冲突）。
- 今天格：`todaySoft` 底。
- 月视图**不显示任务开始时间**，时间留给周/日视图与抽屉；hover tooltip 补全信息。
- 跨天条：实心低饱和填充 + 左侧 3px 项目色；与任务条（无填充 + 小圆点）拉开层次。

## 6. 抽屉结构

```
头部 72：日期卡（44×44）｜ 11月 · 周六 [今天] / 第 46 周 · 今天 ｜ ‹ › ×
分隔线
时间轴（滚动）
  ├─ 有时间的任务（按开始分钟升序）
  ├─ 虚线分隔「未安排时间」
  └─ 空态：「今天还没有安排」+ 主按钮
分隔线
当日备注：标题行 + 多行输入 + 保存状态
```

- 头部日期卡：今天用 accent 实底，其余用 `surfaceSunken`。
- 任务条目高度 ≥ 44，hover 才出现操作按钮；完成后标题降为 `textTertiary` + 删除线。
- 重叠：橙角标 ⚠，不阻止保存。
- 备注自动保存防抖 600ms，显示「已保存」轻提示。

## 8. 组件与状态规范

| 组件 | 规范 |
|---|---|
| 主按钮 | accent 底、白字、高 34、圆角 6、无阴影、hover 加深 |
| 次按钮 | 白底、1px border、`textPrimary`、hover `surfaceHover` |
| 图标按钮 | 32×32、圆角 6、hover `surfaceSunken`、图标 20 |
| 复选框 | 16×16、圆角 4、选中 accent 底白勾 |
| 输入框 | `surfaceSunken` 底、1px border、聚焦 1.5px accent |
| 胶囊标签 | 高 20、左右 6、字号 10–11、圆角 999 |
| Tooltip | 深墨底、白字 12、圆角 6、等待 400ms |
| 滚动条 | 宽 6、圆角 3、默认 30% 灰、hover 55% 灰 |

状态：

- hover：120ms 过渡，背景变化不改变布局；
- 选中：`accentSoft` + accent 边框/竖线；
- focus：2px accent 40% 外发光（键盘可见）；
- disabled：40% 不透明度，光标 `basic`，必须配 tooltip 说明原因；
- loading：骨架占位，不用转圈；
- 空态：一句话 + 一个主操作 + 插画级留白。

## 9. 文案规范

- 全中文，短句，动词开头：`新建任务`、`回到今天`、`未安排时间`。
- 不出现技术词：用「演示数据」而不是 "mock"；用「后续版本」而不是 "TODO"。
- 数量格式：`+3 项`、`2 条安排`、`完成 3/7 · 43%`（数字前后不加空格）。
- 日期格式：`2026年11月`、`11月14日 周六`；时间 `09:00–10:30`（en dash）。
- 错误提示：说明"发生了什么 + 怎么办"，例：「任务已被其他操作修改，请刷新后重试」。

## 10. 无障碍与键盘

- 全局：`Esc` 关闭抽屉；`T` 回到今天。V1.5 增加 `Ctrl+N` / `/` / `Space`。
- 焦点可见：不要全局移除 focus ring；自绘控件需补 `Focus` 状态。
- 对比度：正文 `#5B6472` on `#FFFFFF` ≈ 5.2:1；`textTertiary` 仅用于辅助信息（≥ 3:1），
  不要用它承载任务标题。
- 不依赖颜色单独传达状态（完成态同时有勾选 + 删除线）。
