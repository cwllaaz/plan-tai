# 计划台 V1.0 · 用户操作说明

## 1. 启动

双击 `jihuatai.exe`。首次启动会自动创建本地数据库，界面为空态（没有项目、没有任务）。

> 必须保留 exe 同目录下的 `flutter_windows.dll`、`data\` 文件夹、`cnativeapi.dll` 等文件；
> 单独复制 exe 无法运行。

## 3. 基本操作

### 3.1 查看月份

- 顶栏 `‹` / `›` 切换上/下个月。
- 点「今天」或按键盘 `T` 回到本月并选中今天。

### 3.2 选中与打开某一天

- **单击**日期格子：选中该日（蓝色左侧竖线），不打开面板。
- **双击**日期格子：选中并展开右侧当日面板。
- 单击格子里的一条任务：选中该日；双击任务则展开面板（任务编辑只在面板内进行）。
- 按 `Esc` 或面板右上角 `×` 关闭面板。

### 3.2.1 右键拖选几天 → 新建跨天安排

1. 在月历空白处**按住鼠标右键**，从起始日拖到结束日（像在桌面上框选图标）。
2. 拖动时连续日期会被框住，鼠标旁显示「11月25日 – 11月28日 · 4 天」。
3. 松开右键 → 弹出「新建跨天安排」：填**名称**、选**颜色**、确认起止日期与说明。
   这个弹窗里**不需要选项目**，保存后先放在「未归类」。
4. 月历上立刻出现这条彩色横条；跨周、跨月会自动分段显示。
5. 之后想归类：**双击横条** → 弹窗底部选「归属项目」（也可以继续留在「未归类」）；
   同一个弹窗左下角有「删除」，二次确认后即删掉这条安排（它名下的任务会保留）。

> 右键拖选只负责"选中哪几天"；左键的单击选中 / 双击开面板不受影响。
> 「未归类」是系统分组，不能删除；把里面的安排逐个改到项目即可清空它。

### 3.3 新建任务

1. 双击某一天打开面板；或点顶栏「新建安排」。
2. 点面板底部「新建任务」。
3. 只填标题也可以保存；时间可留空（当天"未安排时间"分组）。
4. 选择项目、优先级、开始时间、备注后保存。
5. 右上角「完成 x/y」与进度条会随勾选实时变化。

### 3.4 修改 / 删除 / 完成

- 鼠标移到任务行，右侧出现编辑 / 删除按钮。
- 勾选框：完成/取消完成，日历与列表同步更新。
- 删除后可在提示条上点「撤销」。

### 3.5 当日备注

- 面板底部「当日备注」输入框，停止输入后自动保存（显示「已保存」）。
- 关闭面板时会立即落库，不会丢失。
- 「当日重点」最多 3 条。

## 4. 项目与跨天阶段

左侧「项目」进入项目管理页：

- **新建项目**：右上角「新建项目」，填写名称、简介、颜色。
- **修改**：选中项目后改名称/简介/颜色/状态，点「保存修改」。
- **归档**：从项目页与侧栏消失，进入「归档」，可「取消归档」。
- **删除**：二次确认后，项目及其全部阶段、任务一起移除（可从备份恢复）。
  项目列表里也可以直接**右键某个项目 → 删除项目**（「未归类」是系统分组，右键里是灰的）。
- **调整顺序**：在项目列表里**长按某个项目上下拖动**，松手即保存；
  左侧栏的项目顺序会同步变化（拖到列表顶部就排最前）。
- **跨天阶段**：项目详情下方「新建阶段」，填名称、颜色、开始日、结束日；
  状态不在弹窗里改（新建默认「计划中」）。
  阶段会以彩条跨越多天显示在月历上；跨周自动分段并显示延续箭头。
- **未归类**：从月历右键拖选创建的安排默认落在这里（一个系统分组，不能删除）。
  想让某条安排归属某个项目：双击月历上的横条，在弹窗底部把「归属项目」改成它即可；
  它名下的任务会一起搬过去。
- 侧栏项目右侧数字为该项目未完成任务数，点击直接进入项目页。

## 5. 任务列表

- 「任务」：全部未完成任务（含未排期），按日期分组；点击一行回到当天面板。
- 「已完成」：已完成任务，可取消勾选恢复为待办。

## 6. 备份与恢复

顶栏 `⟳`（本地备份与恢复）：

- **立即备份**：在 `%APPDATA%\计划台\data\backups\` 生成 `jihuatai-backup-时间.json`。
- **恢复**：列表里点某个备份的「恢复」→ 确认 → 整体替换本地数据；
  恢复前会自动生成当前数据快照，失败自动回滚。
- **打开备份文件夹**：在资源管理器中查看备份文件。

## 7. 设置

顶栏 `⚙`：查看应用版本、数据库位置、运行模式、云同步只读汇总；可打开数据文件夹和云同步面板。

## 7.1 云同步（V2）

1. 点顶栏云状态按钮（未登录时显示「未登录」）。
2. 填服务器地址（正式环境用 `https://`，本机开发可用 `http://127.0.0.1:8090`）、账号或邮箱、密码。
3. 登录后如提示「待确认关联」，按本机/云端数据量选择：
   - 本机有数据、云端为空：可「上传本机数据到该账号」（会先整库备份）；
   - 云端有数据、本机为空：创建本机工作区并下载云端数据；
   - 两边都有：只能「以云端为准（先备份并归档）」或保持本地，不会自动合并。
4. 需要重启时，关闭应用再打开即可（工作区指针已保存在 `cloud_workspace.json`）。
5. 已连接后：顶部显示「已同步 / N 项待上传 / 存在冲突 / 离线」；面板里有「立即同步」
   与「自动同步」开关。
6. 冲突时不会丢数据：冲突页可看双方版本，选择保留本机或云端。
7. 退出账号：面板底部「断开云端绑定」——**不会删除本地数据**。

## 9. 常见问题

**Q：双击 exe 提示「无法创建本地数据目录 / 无法打开数据库」？**
检查 `%APPDATA%\计划台\data\` 是否可写、磁盘是否已满；程序不会删除或重建你的数据。
若只是想在无数据库情况下看界面，可设置环境变量 `JIHUATAI_DEMO=1` 启动演示模式。

**Q：数据存在哪里？换电脑怎么迁移？**
`%APPDATA%\计划台\data\app.db`。推荐用「立即备份」导出 JSON，在新电脑上用「恢复」导入，
而不是直接复制 db 文件（WAL 模式对文件拷贝不友好）。

**Q：没网还能用吗？**
能。月历、项目管理、任务、备注、备份恢复全部本地；顶栏显示「离线」，联网后自动继续同步。

**Q：登录后为什么有两个 `app.db`？**
选择「以云端为准/新建工作区」时会创建 `accounts\<ownerId>\app.db`，原 `app.db` 原样保留
（并做过备份/归档）；`cloud_workspace.json` 记录当前打开哪个库。删除该指针文件即可回到
默认本地库（不会删除任何数据）。
