# 计划台 Android · 移动端 UI 规范（UI_SPEC）

> 适用范围：Android 手机与平板（Flutter 单工程，按**实际可用宽度**布局）。
> 设计基线：`docs/UI_SPEC.md`（V1 已确认的浅色设计）+ `lib/core/theme/tokens.dart`（唯一令牌来源）。
> 本文件只新增**移动端**规则；与桌面冲突时，桌面行为以 `docs/UI_SPEC.md` 为准。
>
> 实现方：月历模块（`lib/mobile/**`）。令牌不得私自定义；缺令牌先提需求，由维护者加入
> `tokens.dart`。

---

## 1. 设计原则（延续 Windows 已确认设计）

1. **高审美浅色主题**：白面 + 极浅灰画布，不用大面积色块；强调色只用于选中、主按钮、今天。
2. **低饱和颜色**：主色 `#3E63DD`，项目色取固定调色板（`ProjectColor`），不使用高饱和荧光色。
3. **简洁的日历网格**：1px 细边框分隔，格子内信息克制（不堆文字）；今天用极淡底色而非描边高亮。
4. **细边框、克制阴影**：分隔靠 1px 边框；阴影只用于浮层（底部面板/对话框）。
5. **统一项目颜色体系**：同一项目在月历横条、任务列表、项目导航中颜色一致。
6. **现代中文字体**：优先 `Noto Sans SC` / 系统 CJK；数字用等宽数字（`AppText.tabularFigures`）防跳动。
7. **触摸优先**：所有可点击目标 ≥ 48×48dp；手势不与桌面右键/悬停语义混用。

## 2. 设计令牌（移动端用法）

| 类别 | 令牌 | 移动端用法 |
|---|---|---|
| 画布 | `AppColors.canvas` `#F7F8FA` | 页面背景 |
| 表面 | `AppColors.surface` `#FFFFFF` | 卡片、月历、底部导航、面板 |
| 下沉面 | `AppColors.surfaceSunken` `#F2F4F7` | 分段控件底、输入框底 |
| 边框 | `AppColors.border` `#E6E8EB` / `borderStrong` | 1px 分隔；按下态可用 borderStrong |
| 文字 | `textPrimary #171A1F` / `textSecondary #5B6472` / `textTertiary #8B94A3` | 标题 / 正文 / 辅助 |
| 主色 | `accent #3E63DD`、`accentSoft #E8EDFB`、`accentBorder #C9D5F8` | 主按钮、选中日、今天的点 |
| 语义 | `success #30A46C`、`warning #F5A524`、`danger #E5484D` | 完成、待处理、错误 |
| 今天 | `todaySoft #F0F4FE` | 今天格背景 |
| 间距 | `AppSpacing`：4/8/12/16/20/24/32 | 一律 4 的倍数；手机页面左右 16，平板 24 |
| 圆角 | 控件 6 / 卡片 8 / 面板 10 / 大面板 14 | 底部面板顶部圆角 14 |
| 字号 | `AppText`：h1 20 / h2 16 / body 14 / small 13 / caption 12 / micro 11 | 月标题 h1（手机可 20），任务标题 bodyStrong |
| 动效 | `AppMotion`：120ms hover / 180ms 月切换 / 200ms 抽屉 | 触摸反馈 120ms；月切换 180ms；底部面板 250ms（系统默认） |

**触摸尺寸**：图标按钮 48dp 命中区；列表行高 ≥ 56dp；勾选框 24dp 图标 + 48dp 命中区。
**禁止**：新色值、渐变背景、超过 1 层的投影、桌面 hover 效果（移动端用按下态/水波纹）。

## 3. 响应式断点（按可用宽度，不按设备类型）

用 `LayoutBuilder` 取**内容区可用宽度**（已扣除安全区/侧边栏），三档：

| 断点 | 宽度 | 布局 |
|---|---|---|
| Compact | `< 600dp` | 手机竖屏：单列；顶部月份 + 月历 + 选中日任务列表 + 底部导航 |
| Medium | `600–839dp` | 大手机/小折叠/竖屏平板：月历 + 选中日列表上下排布，底部导航改为 NavigationRail（可选） |
| Expanded | `≥ 840dp` | 平板横屏：左侧项目导航 200–240dp + 中间月历 + 右侧当日面板 320–400dp（复用桌面思想） |

- **不得**用 `Platform.isAndroid` 判断手机/平板；同一 APK 在平板、折叠屏、分屏窗口都要正确。
- 切换断点时保留 `PlannerShellState`（选中日期/月份/分区）不重置。
- 最小可用宽度按 320dp 验证不溢出；高度按 640dp（含系统栏）验证不溢出。

## 4. 手机端（Compact）

### 4.1 结构

```
┌─────────────────────────────────────────────┐
│  ‹   2026 年 11 月   ›        [同步状态] [今天] │ 56dp，SafeArea 顶部
│      今天 11 月 15 日 · 周六                   │
├─────────────────────────────────────────────┤
│  一   二   三   四   五   六   日             │ 星期表头 28dp
│  ┌───┬───┬───┬───┬───┬───┬───┐               │
│  │   │   │   │   │   │   │   │  ← 月历网格   │ 6 行 × 每行 ≥ 52dp
│  │   │   │   │   │   │   │   │               │
│  └───┴───┴───┴───┴───┴───┴───┘               │
├─────────────────────────────────────────────┤
│  11 月 15 日 · 周六        3 项 · 完成 1 项    │ 选中日摘要
│  ○ 09:00 晨会                    ● 项目色     │ 任务行 ≥ 56dp
│  ○ 写周报                        ●           │
│  ＋ 新建任务                                  │
├─────────────────────────────────────────────┤
│   日历      项目      任务      我的           │ 底部导航 56dp + 安全区
└─────────────────────────────────────────────┘
```

### 4.2 顶部栏

- 左：上个月 `‹`（48dp）；中：月份标题 `h1` + 副标题「今天 M 月 D 日 · 周X」`caption`；
  右：同步状态图标（只表达状态，不承载操作）+「今天」文字按钮。
- 月份标题过长时省略（`ellipsis`），不得换行挤压。
- 点击月份标题：打开月份/年份快速选择（月历模块 可选实现；不强制）。

### 4.3 月历网格

- 固定七列（周一为第一列，与桌面一致）；行数按月份 4–6 行，**填满剩余高度**（任务列表在下方时月历最高占 55%）。
- 格子内容预算（手机）：日期数字（12–13sp）+ 最多 2 个任务圆点/1 条跨天横条 + `+N` 折叠计数。
- 今天：`todaySoft` 背景 + 日期数字用 `accent` 加粗；选中：`accentSoft` 背景 + 1px `accentBorder`。
- 跨天安排：格子顶部细横条（项目色，4dp 高，圆角 2dp）；跨格连续时视觉上要连续（与桌面一致）。
- 相邻月日期：文字 `textDisabled`，仍可点（点了切换月份并选中，由外壳处理）。
- 手势：
  - **单击**：选中日期，刷新下方任务列表（不弹面板）。
  - **双击**：打开该日详情（底部面板/全屏页）。
  - **长按**：进入「新建安排」的日期区间选择（可选，月历模块 决定；若不实现需在 UI 上不暗示）。
  - **左右滑动月历区域**：切换上/下个月（可选；若有，必须与内部点击手势不冲突）。
- 禁止：格子里放超过 1 行的任务标题（信息过载、点击目标过小）。

### 4.4 选中日任务列表

- 标题行：日期 + 星期 + 「N 项 · 完成 M 项」；右侧「＋」新建。
- 任务行：勾选圈（左）→ 标题（bodyStrong，完成态删除线 + `textTertiary`）→ 项目色点 → 固定时间（`numeric`，可选）。
- 行高 ≥ 56dp；整行可点进入编辑（底部面板/全屏页）；勾选圈独立命中 48dp。
- 空态：居中浅灰插画位（可无图）+「今天还没有任务」+ 主按钮「新建任务」。
- 列表滚动到月历下方，不与月历抢滚动；月历本身不滚动（固定网格）。
- 下拉刷新：不实现（本地数据是流式刷新）。

### 4.5 底部导航

- 4 项：`日历` / `项目` / `任务` / `我的`；图标 + 10–11sp 标签；高度 56dp + 底部安全区。
- 选中项：`accent` 图标与文字；未选中：`textTertiary`。
- 切换分区保留各分区滚动位置与 `PlannerShellState`；从 `项目` 点具体项目进入项目详情（可全屏页）。
- 「我的」承载：账号/同步、备份与恢复、设置、关于（桌面顶栏的云/备份/设置入口在移动端收敛到这里）。
- 系统返回键：在非「日历」分区先回到「日历」；在日历分区再返回则退出应用（不要直接杀进程之外的花活）。

### 4.6 任务编辑（手机）

- 使用**全屏页**或 `showModalBottomSheet(isScrollControlled: true)` + 键盘避让；推荐底部面板（`DraggableScrollableSheet` 或 `FractionallySizedBox(heightFactor: 0.9)`）。
- 字段顺序：标题（必填，自动聚焦）→ 项目 → 日期 → 固定时间（可选）→ 优先级 → 备注 → 删除（编辑态）。
- 保存：右上「保存」文字按钮；取消：左上「取消」或下滑关闭；有未保存改动时二次确认。
- 校验错误就地展示（标题为空、时间格式、结束早于开始），不弹全局 SnackBar 代替字段错误。
- 完成/取消完成不进入编辑器：列表勾选即可，失败时回滚并提示。

### 4.7 每日备注

- 位于当日面板/全屏日详情底部：「今日备注」多行输入 + 「今日重点」最多 3 条（单条 60 字）。
- 防抖 600ms 自动保存；状态文案：`正在保存…` / `已保存` / `保存失败，点击重试`。
- 切日期/关闭面板前强制落库（复用桌面逻辑），不得丢草稿。

## 5. 平板端（Expanded，≥840dp）

优先复用 Windows 桌面布局思想，但做成触摸版：

```
┌──────────┬───────────────────────────────┬──────────────────────┐
│ 计划台    │  2026 年 11 月      [同步] [今天] │  11 月 15 日 · 周六    │
│          │  一 二 三 四 五 六 日            │  3 项 · 完成 1 项      │
│ 日历      │  ┌───────────────────────────┐  │  ○ 09:00 晨会         │
│ 项目      │  │                           │  │  ○ 写周报             │
│   · 工作  │  │        月历（大格）        │  │  ────────────         │
│   · 生活  │  │                           │  │  今日备注              │
│ 任务      │  └───────────────────────────┘  │  [多行输入]            │
│ 已完成    │                                 │  ＋ 新建任务           │
│ 归档      │                                 │                      │
└──────────┴───────────────────────────────┴──────────────────────┘
   200–240dp            自适应                    320–400dp
```

- 左侧项目导航：分区（日历/项目/任务/已完成/归档）+ 项目列表（颜色点 + 名称 + 计数），可滚动；
  选中项目高亮 `accentSoft`。宽度 200–240dp，可折叠为 56dp 图标栏（可选）。
- 中间月历：格子高度随可用高度，最小 72dp；信息预算可放宽到 3 条任务/2 条横条。
- 右侧当日面板：直接复用 `DayDetailPanel`（语义与桌面一致），宽度 320–400dp，始终展开；
  未选中日期时显示「选择一天查看任务」。
- 顶部栏：月份切换 + 今天 + 同步状态；搜索可后续加，不在本期。
- 平板分屏（窗口宽度 < 840dp）自动降级为 Medium/Compact 布局，不出现三栏挤压。

## 6. 项目与颜色

- 项目色来自 `ProjectColor`（固定调色板）；新建项目自动取色，编辑时可改。
- 项目列表行：色点 10dp + 名称（bodyStrong）+ 任务计数（caption）+ 右侧菜单（编辑/归档/删除）。
- 「未归类」是系统项目：不可删除、不可归档，颜色固定（与桌面一致）。
- 归档项目只在「归档」分区展示，默认月历不显示其任务（与桌面语义一致：归档项目任务仍存在但默认不展示，
  具体以 `ProjectsPage`/仓储过滤为准，不得自行新造规则）。
- 删除项目：二次确认文案必须说明「会级联删除其下安排与任务（软删除，可恢复）」；
  移动端用 `AlertDialog` 或底部确认面板，危险按钮用 `danger`。

## 7. 云端账号与同步状态（移动端）

- 入口：手机「我的」→「账号与同步」；平板可放顶部状态图标旁。
- 状态表达（只读图标/文案）：
  - 已登录且空闲：`cloud_done_outlined` + 「已同步」；
  - 同步中：`sync` 旋转 + 「同步中…」；
  - 离线：`cloud_off_outlined` + 「离线，改动将在联网后上传」；
  - 需处理（冲突/绑定/过期）：`error_outline` + 「需要处理」，点击进入；
  - 未登录：`cloud_off_outlined` + 「未登录」。
- 未登录/离线时，本地功能完全可用；不得弹出阻塞式登录墙。
- 登录页：服务器地址（默认上次保存）、账号、密码（默认遮挡 + 可切换）、登录按钮、错误文案；
  服务器地址必须 https（localhost 例外），输入校验就地提示。
- 首次绑定：必须让用户明确选择（上传本机 / 以云端为准并归档本机 / 暂不关联 / 取消），
  说明文字与桌面一致；「以云端为准」必须有二次确认 + 备份路径提示。
- 冲突：列表 + 每条冲突的「保留本机 / 保留云端 / 手动合并」；移动端全屏页展示，不塞进小弹窗。
- 下载前有未上传改动：二次确认（与桌面一致）；「覆盖本机」是危险操作，红色按钮 + 明确后果说明。
- 退出登录：不删除本地数据，文案说明。

## 8. 状态与反馈

| 状态 | 规范 |
|---|---|
| 加载 | 月历/列表首帧用骨架或浅灰占位，不用全屏 spinner；超过 300ms 才显示 |
| 空 | 一句说明 + 主操作按钮；不显示“错误”语气 |
| 错误 | 就地文案（SnackBar 仅用于跨页面操作结果）；可重试的给「重试」 |
| 成功 | 轻量 SnackBar（2–3s），不做全屏庆祝 |
| 危险操作 | 二次确认 + 明确后果 + 红色主按钮 |
| 删除任务 | 立即从列表移除 + SnackBar「已删除 · 撤销」，撤销恢复原位置 |

## 9. 可访问性与国际化

- 文字缩放：`MediaQuery.textScaler` 最多 1.3× 不溢出；月历格子内文字允许省略，不换行撑破。
- 对比度：正文 ≥ 4.5:1；`textTertiary` 只用于辅助信息，不用于关键操作。
- 图标按钮必须有 `tooltip`/`Semantics(label:)`；勾选圈提供「完成/取消完成」语义。
- 语言：`zh_CN` 为默认；保留 `en_US` 兜底，不新造硬编码英文。
- 横竖屏：手机横屏时月历与列表上下排布仍可用；平板横屏三栏。
- 手势替代：双击展开日面板必须有等价的显式入口（点日期后列表上方「展开当日」按钮），照顾不可双击场景。

## 10. 文案规范（与桌面一致）

- 用「安排」表示跨天阶段，用「任务」表示单日事项；避免「阶段/条目/事项」混用。
- 时间格式：`HH:mm`；日期格式：`M 月 D 日 · 周X`；月份标题：`YYYY 年 M 月`。
- 按钮动词一致：「新建任务」「新建安排」「保存」「取消」「删除」「恢复」「同步」「上传」「下载」。
- 错误文案给「原因 + 下一步」，不暴露 HTTP/异常栈。
- 不使用「亲/哦」等口语；不使用感叹号堆叠。

## 12. 验收（月历模块 交付时必须附截图/测试）

1. 320×640、360×800、412×915（手机）无溢出；600×960、800×1280、1280×800（平板）布局正确。
2. 月历七列、今天/选中/相邻月/跨天横条/折叠计数全部可见且不重叠。
3. 单击选中、双击/显式入口打开当日、勾选完成、撤销删除、备注自动保存全部可用。
4. 底部导航四个分区切换正常，返回键行为符合 §4.5。
5. 离线（`cloudController == null`）时顶栏显示未登录/离线，不崩溃、不弹登录墙。
6. 文字缩放 1.3× 时无溢出。
7. 使用 `InMemoryPlannerRepository` 的 widget 测试覆盖至少：空态、任务列表、面板打开/关闭、
   备注保存、底部导航切换。
