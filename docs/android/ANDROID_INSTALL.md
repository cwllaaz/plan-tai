# 计划台 Android · 安装与首次使用

> 随包说明见 `dist/android/安装说明.md`；签名与升级见 `ANDROID_SIGNING_AND_RELEASE.md`。

## 1. 安装

- 正式包：`dist/android/计划台-1.0.0-arm64-v8a-release.apk`（Android 7.0+，arm64 设备）。
- 手机：传到手机后点开 APK，按系统提示允许「安装未知应用」→ 安装 → 打开。
- 开发机：`adb install -r 计划台-1.0.0-arm64-v8a-release.apk`。

## 2. 首次启动

1. 应用自动在私有目录建库，**不需要登录、不需要联网**即可使用月历/任务/项目/备注。
2. 需要云同步：「我的 → 账号与同步」→ 服务器地址（正式环境必须 `https://`）+ 账号 + 密码 → 登录。
3. 首次登录会询问数据归属：
   - 本机无数据、云端有数据 → 选择「以云端为准」，重启应用后自动全量下载；
   - 本机有数据、云端为空 → 选择「上传本机到账号」；
   - 两端都有数据 → 必须手动选择，应用不会自动覆盖。
4. 登录后：打开应用/回到前台/保存改动后会自动同步；也可在账号页点「立即同步」。

## 3. 权限

- 只申请 `INTERNET` 与 `ACCESS_NETWORK_STATE`；**不申请存储权限**。
- 备份导出/导入使用系统文件选择器（SAF），由用户在系统 UI 里授权单个文件。

## 4. 卸载前

先「我的 → 数据与备份 → 导出备份到文件」，或确认数据已同步到云端；卸载会删除本地全部数据。
